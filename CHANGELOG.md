# Changelog

All notable changes to this pack. Dates are UTC.

Each release raises the version in .claude-plugin/plugin.json. A change to a SKILL.md also raises that skill's metadata.version: the last number for wording, the middle number for new steps, rules or sources.

## 1.2.3 - 2026-11-28

- bsv-facts 1.2.1: answers Bitcoin SV (BSV) questions from the matching page on bitcoinsv.it, with the link.
- paymail-lookup 1.1.0: checks a Paymail handle before you pay it, using public lookups only.
- bsv-whale-watch 1.0.2: follows the 100 largest BSV addresses with the bitcoinsv.it rich list, its label list and weekly snapshots, plus WhatsOnChain or Bitails for single addresses.

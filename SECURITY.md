# Security

Report security problems by email to contact@bitcoinsv.it, not in a public issue.

You can also report one privately on GitHub. Open this repository's Security and quality tab, then click Report a vulnerability.

Examples of what to report:

- Skill text that could lead an agent to ask for, repeat or use a seed phrase, a private key or another wallet secret.
- Skill text that could lead an agent to move funds.
- Skill text that could lead an agent to send user data to a host that PRIVACY.md does not list.
- A file in this repository that holds a secret or personal data.

For an outdated fact, open an issue in this repository.

Fixes ship in a new release, listed in CHANGELOG.md. Only the latest release is supported.
